# Smart Health App — User Stories

## 1. User Registration
As a new user, I want to create an account using my name, email, and password so that I can access my personal health information.

## 2. User Login
As a registered user, I want to log in securely so that I can access my saved wellness information.

## 3. View Dashboard
As a user, I want to see a dashboard with my wellness options so that I can easily navigate the app.

## 4. Create a Wellness Plan
As a user, I want to enter information about my daily activities, sleep routine, goals, and food preferences so that I can receive relevant wellness suggestions.

## 5. View Wellness Recommendations
As a user, I want to view recommendations based on the information I provide so that I can find practical ways to support my wellbeing.

## 6. Save Health Records
As a user, I want my wellness plans and health records to be saved to my account so that I can access them later.

## 7. View and Manage Health Records
As a user, I want to open, review, and delete saved health records so that I can manage my information.

## 8. Save Favourite Items
As a user, I want to save useful wellness tips or recommendations as favourites so that I can find them easily later.

## 9. Manage App Settings and Notifications
As a user, I want to manage my app preferences and notification settings so that I can control how I use the app and receive reminders.
